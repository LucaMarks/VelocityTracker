# VelocityTracker
This project involved optically capturing footage of falling hailstones during hailstorms, extracting the speed of each individual hailstone, and using this data to help calculate the kinetic energy of each falling hailstone using E = (1/2)m(v^2). We were able to accomplish this by taking advantage of the ComputerVision API to detect falling hailstones as objects. The main challenge we faced when dealing with this project was being able to detect falling hailstones on a low frame-rate. Hailstones were often very blurry when they were captured on camera. The following techniques were implements into our code to help combat this: Gaussian Blur, Grayscale imaging, Threasholding.
